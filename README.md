# 🚀 Space Invaders

A classic **Space Invaders** arcade game, developed in **Python** using **Pygame**.

![Space Invaders Gameplay]

---

## 🎮 Features
- Enemy alien spaceships with smooth horizontal movement  
- Player-controlled spaceship with responsive left/right movement  
- Shooting mechanics with bullets and collision detection  
- Scoring system that increases when enemies are hit  
- Game Over screen when enemies reach the bottom of the screen  
- Multiple enemies with random respawn positions  
- Animated background for immersive gameplay  

---

## 📦 Installation

1. Install **Python 3.x** if not already installed.  
2. Install **Pygame**:
